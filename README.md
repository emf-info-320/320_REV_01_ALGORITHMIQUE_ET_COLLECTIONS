# S'entraîner à résoudre des problèmes avec ces nouveaux outils

## Objectifs visés

Constat : Java n'est que rarement le problème, c'est l'absence de démarche claire, précise et mentalisée qui l'est le plus souvent !

Les objectifs poursuivis par ces petits exercices d'entraînement sont :

- **S'entraîner à résoudre des problèmes** (algorithmique) à l'aide de ces nouvelles collections intelligentes
- S'entraîner à **réfléchir avant d'agir**, à trouver une façon de faire simple et explicable, une approche, ... permettant de résoudre chacun des petits problèmes ci-dessous (=algorithmique)
- Utilisation de collections spécifiques adaptées afin de **réduire le code nécessaire** et **faciliter le codage**
- **Améliorer l'aisance** et le niveau et la compréhension des bases de Java
- Entraînement à de l'algorithmique simple

## Contenu

Ce projet gitté contient :

- **plusieurs exercices d'entraînement** pour travailler l'algorithmique face à quelques petits problèmes d'une difficulté progressive.

## Principes d'utilisation

Les postes de travail pouvant être refaits à tout moment, le travail pouvant être commencé à l'EMF et poursuivi à la maison ou le contraire, ..., l'idée est de `commit`/`push` au moins 1x en fin de journée afin que le cloud soit toujours la source de référence **à jour** (comme déjà entraîné au D400).
